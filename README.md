## 📌 1. 권장 개발 환경 및 유니티 버전

이 프로젝트는 아래의 Unity 버전을 기준으로 제작되었습니다. 다른 버전을 사용할 경우 패키지 충돌이나 호환성 문제가 발생할 수 있으니 가급적 동일한 버전을 권장합니다.

> 3. 목록에서 `6000.4.10f1` 버전을 찾아 설치합니다. (목록에 없을 경우 Unity 공식 다운로드 아카이브에서 `Unity Hub 링크`로 추가할 수 있습니다.)

## 📥 2. 프로젝트 다운로드 방법

깃(Git) 사용 여부에 따라 편한 방법을 선택해 다운로드하세요.

### 방법 A. ZIP 파일로 간편하게 다운로드 (Git을 모르는 경우 추천 👍)

GitHub이나 원격 저장소 사용이 처음이라면 브라우저에서 바로 압축 파일로 다운로드할 수 있습니다.

1. **저장소 페이지 접속:** 프로젝트 GitHub 페이지 메인 화면으로 이동합니다.
2. **Code 버튼 클릭:** 상단 초록색 **`<> Code`** 버튼을 클릭합니다.
3. **ZIP 다운로드:** 드롭다운 메뉴 맨 아래의 **`Download ZIP`** 버튼을 클릭합니다.
4. **압축 해제:** 다운로드된 `.zip` 파일의 압축을 원하는 폴더에 풉니다.
   - *주의:* 압축을 풀었을 때 생성되는 최상위 폴더 안에 `Assets`, `ProjectSettings` 폴더 등이 바로 보이는지 확인하세요.

---

### 방법 B. Git Clone으로 다운로드 (Git 사용 가능한 경우)

Git이 설치되어 있는 경우 터미널(Terminal) 또는 명령 프롬프트(CMD)에서 아래 명령어를 실행하세요.

```bash
# 저장소 복제 (HTTPS)
git clone [https://github.com/](https://github.com/)[사용자명]/[저장소이름].git

# 해당 디렉토리로 이동
cd [저장소이름]
